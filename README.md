# Hodgkin–Huxley Neuron Modelling

MATLAB/Simulink academic project implementing and examining the Hodgkin–Huxley model of neuronal membrane dynamics. The model represents the membrane potential and voltage-dependent ionic currents and gates, and is explored under different stimulation signals.

## Contents
- `model/`: Simulink models.
- `analysis/`: MATLAB Live Script and plotting scripts.
- `report/`: Original project report.
- `images/`: Screenshot supplied for the portfolio.

## Tools
MATLAB, Simulink.

## Notes
This is coursework, not a validated clinical simulator. Results depend on the stimulus and model settings. Model files may require MATLAB/Simulink and compatible toolboxes.
